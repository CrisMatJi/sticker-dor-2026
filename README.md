# Sticker d'Or Tournament 2026

Bracket editable del torneo de stickers de WhatsApp. Toca una casilla para elegir sticker, poner votos o pasarlo a la siguiente ronda. **Compartir** envía el enlace o una captura del cuadro.

## Datos compartidos

Los cambios se guardan en una Firebase Realtime Database (plan gratuito). La URL de la base de datos va en `config.js`.
